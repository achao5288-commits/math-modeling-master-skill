## 工作流程

### 阶段一：破题与建模 🧠（前40%时间）

1. 仔细读题，标记关键数据和约束条件
2. 判断题目类型（机理/优化/评价/预测/统计/混合）
3. 做出合理假设，写明假设依据
4. 建立数学模型：定义变量和参数 → 写出数学表达式（LaTeX） → 说明理论基础
5. 分析模型可行性与优缺点

### 阶段二：求解与实现 🤖（中间30%时间）

1. 根据模型选择算法
2. 编写 Python 代码（优先）或 MATLAB 代码
3. 数据可视化（遵循"一图胜千言"原则）
4. 结果分析与灵敏度检验
5. 模型修正与迭代

### 阶段三：论文撰写 ✍️（后30%时间）

1. 撰写摘要（最重要！反复打磨，评分的50%以上）
2. 按标准格式组织全文：摘要 → 问题重述 → 假设与符号 → 模型建立与求解 → 检验与分析 → 评价与改进 → 参考文献 → 附录
3. 制作精美图表（流程图、结果图、对比图）
4. 检查格式、排版、引用
5. 团队交叉审阅

## 算法武器库

### 按问题类型速查

**🔴 优化类**
- 经典：线性规划、整数规划、非线性规划、动态规划
- 启发式：遗传算法(GA)、粒子群算法(PSO)、模拟退火(SA)、蚁群算法(ACO)、差分进化(DE)
- 多目标：NSGA-II、Pareto最优、加权法、ε-约束法
- 工具：`scipy.optimize`、`cvxpy`、`deap`、`pymoo`

**🟠 预测类**
- 统计：ARIMA/SARIMA、灰色预测GM(1,1)、多元回归
- 机器学习：BP神经网络、LSTM、SVR、随机森林、XGBoost
- 概率：马尔可夫链、贝叶斯预测
- 工具：`statsmodels`、`sklearn`、`prophet`

**🟡 评价类**
- 主观赋权：层次分析法(AHP)、网络层次分析法(ANP)、模糊综合评价
- 客观赋权：熵权法、TOPSIS、灰色关联分析、CRITIC法
- 降维：主成分分析(PCA)、因子分析
- 效率：数据包络分析(DEA)

**🟢 分类与聚类**
- 分类器：SVM、逻辑回归、决策树、随机森林、XGBoost、LightGBM
- 聚类：K-means、DBSCAN、层次聚类、GMM
- 判别：Fisher判别、贝叶斯判别

**🔵 图论与网络**
- 最短路径：Dijkstra、Floyd-Warshall、A*
- 网络流：最大流、最小费用流
- 经典问题：TSP、VRP（OR-Tools或自定义启发式）
- 工具：`networkx`

**🟣 微分方程建模**
- ODE建模 + 龙格-库塔法求解
- PDE：热传导方程、扩散方程
- 经典模型：SIR/SEIR传染病、Lotka-Volterra种群、Logistic增长
- 工具：`scipy.integrate`、`sympy`

**⚪ 统计方法**
- 假设检验：t检验、卡方检验、ANOVA
- 相关性：Pearson/Spearman/Kendall
- 回归诊断：多重共线性(VIF)、残差分析
- 非参数：Friedman检验、Mann-Whitney U
- 重抽样：Bootstrap、蒙特卡洛模拟

### 华数杯题型→算法映射

| 题目特征 | 首选方法 | 备选方案 |

## 论文写作铁律

### 摘要模板（500字以内）

必须包含：
- **问题背景**：一句话点明研究问题
- **建模方法**：针对问题一建立了XX模型，问题二采用了YY算法
- **核心结果**：给出具体数值（误差X%，最优解Y，精度Z）
- **创新亮点**：本文的创新点在于...
- **最终结论**：模型有效解决了...具有...应用价值

### 论文结构检查清单

- [ ] 摘要：500字以内，有具体数值结果
- [ ] 问题重述：用自己的话重新组织
- [ ] 模型假设：逐条列出并解释合理性
- [ ] 符号说明：三线表，按字母顺序排列
- [ ] 模型建立与求解：论文核心，占正文60%+
- [ ] 灵敏度分析：关键参数±10%扰动（**必做！**）
- [ ] 误差分析 + 基准方法对比
- [ ] 模型评价：3-4条优点 + 2-3条缺点及改进
- [ ] 参考文献：至少5篇含中英文
- [ ] 附录：完整代码 + 大型数据表

### 图表规范

- ✅ 每张图/表独立编号，有标题
- ✅ 配色统一、分辨率≥300dpi
- ✅ 坐标轴有标签和单位
- ✅ 多条曲线用不同线型 + 图例

## 各题型解题范式

### 机理建模类（A题）
1. 画系统示意图 → 标注物理量
2. 从基本原理出发推导方程
3. 引入合理假设简化模型
4. 选择数值求解方法（有限差分/有限元/Runge-Kutta）
5. 用实验/附件数据验证模型
6. 在验证后的模型上做优化

### 优化调度类（B题）
1. 明确目标函数（单目标或多目标）
2. 列出所有约束条件（硬约束 vs 软约束）
3. 判断问题规模 → 小规模精确算法，大规模启发式
4. 设计编码方案 + 适应度函数
5. 算法参数调优
6. 与贪心/随机基准对比，证明算法优越性

### 数据分析类（C题）
1. 数据预处理（缺失值、异常值、标准化）
2. 探索性数据分析EDA
3. 选择合适的模型（分类/回归/聚类/评价）
4. 模型训练 + 交叉验证 + 调参
5. 结果可视化（热力图、箱线图、雷达图）
6. 业务解读 → 把统计结果翻译成通俗结论

## 常见错误与避坑

| 错误 | 正确做法 |
|------|----------|
| 摘要写得像引言，没有数值 | 摘要必须有具体数字结果 |
| 假设不说明理由 | 每条假设配一句解释 |
| 模型与问题脱节，套模板痕迹重 | 从具体问题出发推导模型 |
| 不做灵敏度分析 | 关键参数±10%扰动，这是重要加分项 |
| 图表没有编号和标题 | 图1/表1 + 标题 + 说明 |
| 代码直接贴正文 | 代码放附录，正文放伪代码/流程图 |
| 忽略模型局限性 | 诚实列出2-3个缺点和改进方向 |
